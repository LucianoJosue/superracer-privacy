Política de Privacidade

Esta Política de Privacidade descreve como o aplicativo Superracer lida com informações do usuário.

Coleta de dados

O aplicativo Superracer não coleta, armazena ou compartilha quaisquer dados pessoais dos usuários.

O aplicativo não solicita informações como nome, e-mail, número de telefone, localização, contatos ou qualquer outro dado pessoal.

Uso de informações

Como não há coleta de dados pessoais, nenhuma informação é utilizada para qualquer finalidade.

Compartilhamento de dados

O aplicativo Superracer não compartilha dados com terceiros.

Permissões

O aplicativo utiliza apenas permissões necessárias para o seu funcionamento básico, não acessando recursos sensíveis do dispositivo do usuário.

Conteúdo do aplicativo

O Superracer é um jogo de corrida em estilo retrô, executado localmente no dispositivo, sem necessidade de conexão com a internet.

Alterações nesta política

Esta Política de Privacidade pode ser atualizada futuramente. Recomenda-se que o usuário revise esta página periodicamente.
